## Описание

Сервер работает с текстом, клиент пишет например UPPER helloworld (текст должен быть слитно), и сервер переделывает текст в HELLOWORLD, также с другими командами, любое другое - ошибка

## Как собрать и запустить

Сборка (укажите, чем собирали):

g++ server.cpp -o server.exe -lws2_32
g++ client.cpp -o client.exe -lws2_32

Запуск: сначала сервер, потом во втором окне клиент.

server.exe
client.exe

## Протокол

Сервер слушает порт **<9000>**. Каждая команда — одна строка, каждый ответ — одна строка. После подключения сервер присылает приветствие.

| Команда | Что делает | Пример ответа |
|---|---|---|
| UPPER | Делает текст заглавным | helloworld - HELLOWORLD |
| HELP | список команд | UPPER, LOWER, REVERSE, LENGTH, QUIT |
| QUIT | завершить работу | BYE |

Ошибки: на любую другую команду или текст сервер присылает ERROR: Unknown Command.

## Пример работы

Скопируйте из консоли клиента настоящий сеанс (5–10 команд, включая хотя бы одну ошибку):

> UPPER helloworld
Server: HELLOWORLD
> LOWER HELLOWORLD
Server: helloworld
> REVERSE helloworld
Server: dlrowolleh
> LENGTH helloworld
Server: 10
> helloworld
Server: ERROR: Unknown Command
> QUIT
Server: BYE

1.
socket() - создание сетевого дескриптора в ОС для работы по протоколу TCP
bind() - привязка сокета к конкретному IP адресу и номеру порта
listen() - пассивный слушающий режим ожидающий очереди входящих подключений от клиентов
accept() - принятие первого подключения из очереди для общения конкретно с этим клиентом

2.

даёт любой свободный временный порт при вызове

3.
Эта функция нужна для перевода 16 битного числа в стандартный сетевой порядок байтов, без этого порт считается неверным

4.
